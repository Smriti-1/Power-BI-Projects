# Insurance Data Analysis | Power BI

## 📌 Project Overview

This project explores insurance data using Microsoft Power BI. It is intended to provide an interactive view of policy information, customer segments, premiums, and claims based on the fields available in the dataset.

The goal is to organize insurance data into useful metrics and visualizations that support business analysis.

## 🎯 Business Objectives

- Understand the distribution of insurance policies.
- Analyze premium-related metrics.
- Explore claim patterns and claim-related measures.
- Examine customer demographics and segments.
- Compare policy types and other available business dimensions.

## 📊 Analysis Areas

The exact analysis depends on the columns available in the dataset. Potential areas include:

- **Policy Analysis:** Policy counts and distribution by policy type.
- **Premium Analysis:** Premium amounts and comparisons across segments.
- **Claims Analysis:** Claim counts, amounts, and patterns, where available.
- **Customer Analysis:** Customer profiles and demographic segments, where available.
- **Trend Analysis:** Changes over time, if date fields are available.

## 🛠️ Tools and Techniques

- **Power BI Desktop** — report and dashboard development
- **Power Query** — data profiling, cleaning, and transformation
- **DAX** — measures and calculated columns
- **Data Modeling** — relationships between relevant tables
- **Visualizations** — cards, charts, tables or matrices, slicers, and filters

## 🔍 Development Workflow

1. Understand the business requirements and dataset.
2. Load the source data into Power BI.
3. Profile the data and check data quality.
4. Clean and transform the data using Power Query.
5. Create relationships between tables, where required.
6. Build DAX calculations for relevant insurance metrics.
7. Design interactive report pages.
8. Validate the calculations and visuals.

## 📈 Key Questions

- How many policies are represented in the dataset?
- How are policies distributed across policy types?
- What premium patterns can be identified?
- What claim trends are visible in the available data?
- How do insurance metrics vary across customer segments?
