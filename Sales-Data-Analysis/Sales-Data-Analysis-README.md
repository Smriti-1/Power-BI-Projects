# Sales Data Analysis | Power BI

## 📌 Project Overview

This project analyzes sales data using Microsoft Power BI to understand business performance, monitor sales trends, and identify products and areas contributing to revenue and profit.

The report is designed to turn sales data into clear, interactive insights that can help stakeholders make informed business decisions.

## 🎯 Business Objectives

- Monitor overall sales and profit performance.
- Identify the top- and bottom-performing products.
- Understand sales trends over time.
- Compare performance across product categories and regions.
- Analyze order quantity and revenue patterns.

## 📊 Analysis Areas

- **Sales Performance:** Review overall sales and profit metrics.
- **Time Trends:** Explore how sales change over time.
- **Product Performance:** Compare products and identify top and bottom performers.
- **Regional Performance:** Examine sales across available geographic areas.
- **Quantity Analysis:** Understand quantities sold alongside revenue.

## 🛠️ Tools and Techniques

- **Power BI Desktop** — report and dashboard development
- **Power Query** — data profiling, cleaning, and transformation
- **DAX** — measures and calculated columns
- **Data Modeling** — relationships, cardinality, and star schema concepts
- **Visualizations** — cards, bar charts, line charts, matrix, slicers, and filters
- **Power BI Service** — report publishing and refresh configuration

## 🔍 Development Workflow

1. Understand the business requirements.
2. Load the source data into Power BI.
3. Profile, clean, and transform the data using Power Query.
4. Identify keys and define table relationships.
5. Build the data model.
6. Create DAX calculations for required metrics.
7. Develop report pages and interactive visuals.
8. Validate the report and publish it where applicable.

## 📈 Key Questions

- How are sales and profit performing?
- Which products perform best and worst?
- How do sales change over time?
- Which categories or regions contribute most to sales?
- How does quantity sold relate to revenue?
